# 汉堡造型解压挂件

## 产品

约 50 mm 直径的汉堡形机械解压挂件。由下至上依次为底面包、肉饼、番茄片、蔬菜片、芝士片和顶面包。外观必须严格遵循用户提供的造型参考图，保留精细的分层和表面细节；参考图已收到：圆润金黄面包、颗粒肉饼、红色厚番茄、起伏菜叶和黄色垂角芝士。

底面包减薄，上沿加圆角，侧面越向下越斜向内收，径向收敛量减弱一半、下沿圆角柔和过渡，顶面包为实心几何，仅保留功能安装孔槽，中央弧度平缓、向肩部渐增，底缘稍向内收。肉饼略减薄，保留当前连续起伏的整体轮廓，侧面加入密集、大小不一的自然凸起和浅凹。芝士边长略小于顶面包直径，尺寸适度收小，俯视四条边为直线，四角不向内收并自然外伸；保留立体下垂造型。顶面包的白芝麻自然散点分布，避免螺旋感；每粒缩短并变圆润，埋入面包的体积通过布尔差集切除。默认保留24粒。番茄斜后侧设闭合D形半圆挂孔，在整个孔口不被遮挡的条件下尽量内收，通过菜叶凹谷方向避让遮挡，番茄片不设挂孔。

## 机械方案

用户指定 KS-9 三角红轴一枚。暂将“三角”理解为三脚普通 KS-9 红轴，此解释尚未作为已验证的精确料号。产品仅利用轴体弹簧回弹，无需电源、控制板、电路板、焊接或固件。

下方各层组成固定主体，中间留四边形容纳空间并设置轴体定位和保持结构。顶面包以底部接口扣装在红轴轴芯上，释放时被轴体顶起，按下时自然接触芝士片，松手回弹。必须核查偏心按压的倾斜、摩擦和回弹；不能只验证中心按压。挂环承力通过固定主体，不能牵拉活动顶面包。

内部结构由设计阶段完成：轴壳安装开口、卡扣支承厚度、壳体与脚柱避让、轴芯连接插入深度、顶面包加强与轻量化，以及必要的防转导向。按实际厂商机械图确定接口，不把粗略轴体包络当作安装孔尺寸。

## 已研究的资料

佳达隆官方普通 KS-9 产品页：https://www.gateron.com/products/gateron-ks-9-switch-set 。该系列标注三脚、红轴线性，红轴操作力 45±15 gf，预行程 2.0±0.6 mm，总行程 4.0 mm max。预行程不是本产品必须达到的按压量，电触发也不是验收目标。KS-9 系列包含其他版本，不将静音版或 Pro 版机械图自动视为普通红轴尺寸证据。

机械零件目录初次检索仅返回不匹配的通用零件，未选择或获取替代轴体。已取得佳达隆官方3D页面提供的普通红轴STEP，型号KS-9H10B045NN-X14；其原始坐标并非居中，装配时按轴芯中心和法兰底面校正。

## 默认值与计算原则

采用分件彩色 3D 打印打样路线；面包暖金色、肉饼棕色、番茄红色、蔬菜绿色、芝士黄色、芝麻白色，最终比例和细节以参考图为准。50 mm 指圆形汉堡主体外径，允许芝士四角外伸，挂绳孔耳、挂绳和挂环不计入；一枚轴体位于中心。

不在轴体尺寸未核实前锁定腔宽、腔深或顶盖高度。设静止时顶面包接触面到芝士片的最小轴向间隙为 g，接触前行程即为 g；需满足 g > 0 且 g 加上制造、安装和倾斜误差仍小于所选轴体可用总行程，让芝士片接触限位先于轴体硬触底。官方 4.0 mm max 仅给出行程上限，不能证明每枚轴体都可安全压满 4.0 mm。

顶面包重量及导向摩擦需要低于实际轴体复位能力；不能用 45 gf 操作力直接当成最小复位力。具体工作间隙、运动避让和限位在机械图核实后通过 CAD 检查，成品手感和回弹仍需打样验证。

## 验收

- 外形与用户参考图一致，主体约 50 mm，六层顺序正确，细节可辨。
- 白芝麻为圆润椭圆自然散点，不呈螺旋；埋入面包的体积已切除。
- 番茄外侧半圆挂孔能装挂绳或挂环，连接到固定主体。
- 指定 KS-9 红轴安装稳固，顶面包连接可靠，金属脚和柱有避让。
- 顶面包有可见释放间隙，按下接触芝士片，松手完整复位；偏心按压不出现设计干涉。
- 运动过程无非预期碰撞，每个打印件适合普通打印床；完成模型检查与当前版本交付后方可称可打印。

## 造型输入

用户提供的造型参考图已收到并用于各层比例、边缘起伏与面包顶轮廓。半圆挂孔由设计补入番茄斜后侧。其余未定机械细节由设计阶段依据厂商资料解决。

轴体、挂绳和单件彩色打印约30–100元，自行打印约3–6小时，外包制作与配送约3–7天。非供应商报价。

## 造型尺寸默认值

底面包厚6.5mm、顶面包高18.5mm、肉饼厚5mm（侧面默认150个随机起伏影响区，径向纹理幅度上限0.65mm）、芝士名义边长38mm，四边俯视为直线、四角外伸并下垂，角部不向内收。底面包上部最大直径暂取45.6mm、未倒圆剖面底径42mm，整个侧面采用上部较直、向下收敛渐强的三次弧线（默认指数3，总径向收敛量仍为1.8mm），上缘圆角1.6mm，下缘圆角默认1.2mm；番茄厚3.75mm（增厚25%），菜叶、芝士、顶面包及芝麻同步抬高0.75mm。顶面包底口暂按半径内收0.9mm、过渡高度2.6mm塑形，底缘圆角2mm（增大一倍）。具体饱满程度和圆顶肩线是可调设计参数。

## 挂绳安装默认值

挂孔与番茄一体打印，承力番茄建议红色PETG。半圆孔内半径2mm、外半径4.2mm，厚3.75mm，孔耳中心离主体中心23.85mm，向斜后侧旋转39.4°；孔耳最外半径28.05mm，整个半圆孔口投影与菜叶留约0.2mm设计余量，通过菜叶凹谷方向避开遮挡，默认穿绳段直径不超过1.5mm。

实心顶盖取消整片空心腔；仅保留十字插孔、导向孔与浅的轴壳运动避让槽。普通PLA全实心打印的重量按模型体积估算，真实红轴的初始复位力未获证实，因此完全复位必须首件实装确认，不能以45gf操作力代替复位力。

四根导向柱各向圆心平移3.2mm（原柱直径），分布半径由14.5mm改为11.3mm，对应顶面包导向孔和芝士让位孔同步移动；柱径和孔径保持原值。
