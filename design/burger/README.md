掌心按压、随身挂绳；饱满、圆润、食物拟真。依据用户修订：底面包厚6.5mm，上沿1.6mm圆角、下沿1.2mm圆角，侧面径向收敛量减半、顶面包高18.5mm、肉饼厚5mm；顶面中央平缓、肩部圆鼓，肉饼保留当前整体轮廓与5mm厚度，侧面加入大量密集、大小不一的自然凸起和浅凹，形成连续起伏表面。芝士为38mm方片，俯视四条直边、四角自然外伸并下垂，不向内收；顶面包保持饱满，改为实心几何，仅留功能孔槽。24粒白芝麻自然随机散布，短圆椭圆，布尔切除埋入面包的体积。正面-y、番茄斜后侧紧凑半圆挂孔、底面z=0。暖金面包、棕肉饼、红番茄、绿菜叶、黄芝士、白芝麻，六层独立成件。

## 制作与装配
底面包→肉饼→番茄→真实轴体→带导向柱菜叶→芝士→带芝麻顶面包。固定接触面使用少量胶水，先干装确认完整回弹及四向偏心按压；轴体、轴芯、导向柱和孔均不得进胶。顶面包可拔下；更换轴体需要拆开胶接固定层。挂孔穿细绳直径不超过1.5mm的挂绳。

六层适合180×180mm打印床。外观层PLA，番茄一体承力挂孔及菜叶导向用PETG。建议0.12mm层高，十字孔优先0.2mm喷嘴或补偿后的精细工艺。实心顶盖仅在底部局部避让槽非配合面支撑，轴芯与导向孔内禁止放支撑；菜叶与肉饼内部台阶需要适当支撑或跨桥，芝士垂角及底面包下缘大圆弧需要适当底面支撑。顶面包与白芝麻保持原位作为同一多色打印件导入切片，不能散开排24个小粒；也可单色打印完整几何后把芝麻凸起涂白。圆顶会有层纹，照片烘烤渐变需要上色。

## 验证边界
轴体官方STEP为融合外形，不能模拟内部弹簧、轴芯滑动和摩擦；复位手感、压配松紧及偏心回弹需首件实装。45gf操作力不等于最小复位力，4.0mm max标注也不保证每枚轴体可压满4mm。造型改动后重新检查实体、芝麻与面包布尔界面、全部静态干涉和约3.10mm工作运动。

红色PETG番茄与半圆挂孔一体成形，共底面z11.5mm、上表面z15.25mm，厚3.75mm；孔内半径2mm、外半径4.2mm，孔耳中心半径23.85mm，从背向+y旋转−39.4°朝右后侧，根部半径20mm。孔耳尽量向内收，最外半径28.05mm；朝向菜叶凹谷，整孔投影目标保留至少0.2mm设计余量。肉饼不含孔耳。

## 检查与实装边界

各食材件为单一有效实体，芝麻为24个色域；当前静态无非预期共享体积。顶盖与芝士最小几何间隙约3.1004mm；向下3.10mm的网格路径以0.05mm步长、0.02mm曲面弦差检查，无提前重叠，先在芝士处接触，导向最小网格间隙约0.296mm。精确实体计算在下压3.100416mm时与芝士接触，接触点示例(7.74359,7.92978,20.049584)mm；压到3.11mm已与芝士重叠，因此3.10mm是食材限位，不应强行压到轴体4mm。官方轴体STEP为融合外形而非运动仿真件，打印件运动检查不验证内部弹簧和轴芯摩擦。

实心顶盖比原空心结构更重。26.49g是全密度PLA估重；厂商45±15gf为操作力，不是初始复位力。是否可从释放位置完整回弹仍缺实物证据，不能报告机械回弹已验证。先干装真实红轴，确认完整回弹及四向偏心按压，再胶接固定层；若未完整回弹，保持用户实心要求并另评估材料或轴体复位能力，不擅自改回空心。

轴壳运动检查：官方融合STEP包含轴芯，不能把其当作完全静止物。依据顶面移动底板5×6.55mm包络排除运动区域后，检查0、0.5、1、1.5、2、2.5、3.100416mm下压位置，收窄后的插座与剩余轴壳包络无重叠，最小间隙0.10mm；此项依赖移动底板包络推断，不是内部弹簧或真实轴体运动证明。必须首件干装，确认芝士先接触且完整回弹。旧6.2mm圆柱插座在同一检查下有干涉，已改为圆角矩形。
